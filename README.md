# Esercizi Tutoraggio – Ingegneria Informatica (A.A. 2025/2026)

Questa repository raccoglie gli esercizi presentati durante le sessioni di tutoraggio del corso di **Ingegneria Informatica – Triennale** dell’anno accademico 2025/2026.  
Gli esempi e le soluzioni sono stati sviluppati in **Python** 2.7 e **Jython**, utilizzando funzioni built-in messe a disposizione dall'ambiente di sviluppo J.E.S. (https://github.com/gatech-csl/jes) e hanno lo scopo di supportare lo studio delle basi della programmazione.

## Struttura della Repository

La repository è suddivisa in più *canali*, ognuno associato a un diverso tutor o percorso. Ogni canale contiene il materiale mostrato durante le rispettive sessioni.

.  
├── tutoraggio_canale1/  
│ ├── <data_lezione_1>/  
│ ├── <data_lezione_2>/  
│ ├── <data_lezione_3>/  
│ └── ...  
└── tutoraggio_canale2/  


### ▶ Canale 1

Il **Canale 1** è organizzato in cartelle giornaliere.  
Ogni cartella contiene tutti i file e gli script utilizzati durante quella sessione di tutoraggio.

All’interno di ogni directory del tipo:

tutoraggio_canale1/lezione_DD_MM_YYYY/


sono presenti:
- esercizi svolti in aula,
- esempi dimostrativi,
- eventuali soluzioni alternative o versioni corrette degli esercizi.
- slide mostrate a lezione

## Obiettivi del Materiale

Il contenuto di questa repo è pensato per:
- Chiarire i concetti di base della programmazione;
- Fornire esempi semplici e concreti;
- Introdurre buone pratiche nella scrittura del codice;
- Supportare lo studio autonomo degli studenti.
- Mostrare possibili esempi di risoluzione degli esercizi assegnati 

## Come Utilizzare il Materiale

1. Clona la repository:
```bash
git clone https://github.com/kobero98/TutoraggioFDI_2025
```
Spostati nella cartella del canale o del giorno desiderato:
```bash
cd tutoraggio_canale1/lezione_DD_MM_YYYY/
```

Esegui gli script Python:
```bash
python nome_file.py
```
oppure utilizzare python tutor: https://pythontutor.com/
oppure utilizzare un ambiente JES
